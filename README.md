## 📖 О проекте

Одностраничный лендинг для кофейни **Aroma**. Создан как демонстрация навыков вёрстки и дизайна: тёмная палитра, крупная типографика, плавные появления блоков при скролле.

Проект адаптируется под любую нишу за несколько минут — достаточно заменить тексты и изображения.

## ✨ Что внутри

- 🎨 **Премиум тёмная тема** с кофейным акцентом
- 🌊 **Плавные анимации появления** через `IntersectionObserver`
- 📱 **Полный адаптив** — от телефона до десктопа
- 🖱️ **Hover-эффекты** на карточках, кнопках и меню
- ☕ **CSS-чашка с паром** — чистая графика, без картинок
- 🎞️ **Бегущая строка** с преимуществами
- ⚡ **Ноль зависимостей** — чистый HTML, CSS, JS

## 🧩 Секции

| Секция | Описание |
|--------|----------|
| **Hero** | Заголовок, подзаголовок, кнопки, декоративная чашка |
| **Marquee** | Бегущая строка с ключевыми преимуществами |
| **О нас** | Три карточки с фишками заведения |
| **Меню** | Восемь позиций с ценами |
| **Галерея** | Четыре фото интерьера в сетке 2×2 |
| **Отзывы** | Три отзыва гостей |
| **CTA** | Призыв к действию |

## 🛠️ Стек

- **HTML5** — семантичная разметка
- **CSS3** — Grid, Flexbox, анимации, градиенты, `backdrop-filter`
- **JavaScript (Vanilla)** — `IntersectionObserver` для скролл-анимаций

## 🚀 Запуск

Проект не требует сборки и зависимостей.

```bash
# Клонировать
git clone https://github.com/furios114/coffee-landing.git
cd coffee-landing

# Открыть
open index.html
```

Или просто открой index.html в браузере.

📁 Структура

```
coffee-landing/
└── index.html    # весь проект в одном файле
```
